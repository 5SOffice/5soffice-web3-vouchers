# Implementation Roadmap v2

## Phase 0 — Product and data alignment

- approve business-first repositioning;
- define initial entitlement catalog and owners;
- define wallet, ledger and redemption schemas;
- define integration with Webapp, Tenant Agent and booking services;
- review legal, financial and campaign terms.

## Phase 1 — Off-chain MVP

- account-based wallet;
- catalog and eligibility;
- grant and balance ledger;
- reservation and redemption state machine;
- signed QR validation;
- reception/admin minimum console;
- audit and reconciliation.

## Phase 2 — AI service credits

- usage-preview API;
- reserve/consume/release integration with AI Suite;
- monthly tenant grants;
- usage history and operator adjustments;
- pilot commercial packages.

## Phase 3 — Campaign and partner functions

- bulk issuance;
- gifting;
- campaign analytics;
- partner rules and controlled APIs.

## Phase 4 — Optional Web3 pilot

- select one low-risk campaign;
- deploy reviewed ERC-1155 adapter on testnet;
- implement mapping and reconciliation;
- test wallet and non-wallet journeys;
- proceed to production only after explicit review.
